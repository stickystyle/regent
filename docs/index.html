The Problem

Your team starts coding too soon

Product says "build user preferences." Engineering jumps straight to code. Three PRs later, you realize nobody asked: preferences per workspace or global? What happens to old data when schemas change? Who can override what?

The bugs weren't in the code. They were in the spec you never wrote.

Regent puts Claude in the room before you write a single line.

Your team huddles in Slack. Claude asks the hard questions — edge cases, trade-offs, constraints — that surface the real requirements before implementation starts. When the spec is done, everyone knows what "done" means.

The Process

From huddle to production

Claude guides your team through structured brainstorming in Slack, then helps you execute with test-driven implementation. Every step keeps humans and AI aligned.

1

Brainstorm Together

Start a Slack huddle and invite Claude to join your team. Claude listens to your verbal discussion while asking one question at a time. It hears debates about trade-offs, catches edge cases mentioned in passing, and references what it heard when asking follow-ups. The whole team contributes, and nothing gets lost.

↓
2

Specify

Transform brainstorm notes into structured requirements using the EARS format. Every "when" and "then" becomes explicit, eliminating ambiguity before design begins.

↓
3

Design

Map out architecture, interfaces, and correctness properties. Define what "working correctly" means before writing any implementation code.

↓
4

Plan

Generate a TDD-ordered task list. Every task follows the pattern: write test → implement → verify. No guessing what to build next.

↓
5

Execute

Implement one task at a time with AI assistance. Each task comes with a detailed brief derived from your spec, keeping you focused and aligned.

The Secret Sauce

Claude doesn't just read — it listens

Voice changes everything. When your team huddles, Claude captures the nuance that text misses.

🎙️

Passive Listening

Claude joins your Slack huddle and transcribes everything. You talk naturally — no need to type out long explanations.

💡

Context-Aware Questions

"I heard you mention concerns about token revocation — should we add a blacklist?" Claude references what it heard to ask smarter follow-ups.

📝

Captures the "Why"

Disagreements, alternatives considered, and reasoning behind decisions all get captured in the spec — not just the final answer.

No real-time streaming complexity. Claude only fetches the transcript when you submit an answer with @regent. Simple, fast, and cheap (powered by Recall.ai).

How It Works

Built for teams, works solo too

Regent brings collaborative spec development to Slack, where your whole team brainstorms with Claude. Need to work solo? The Claude Code plugin has you covered.

🤝

Team Collaboration

Brainstorm with Claude in Slack huddles — Claude listens and transcribes your verbal discussions. Specs live on GitHub Epics as collapsible comments (no repo write access needed). Tasks become GitHub issues your team picks up together.

Working alone? Use the Claude Code plugin to run the same workflow from your terminal. Specs live locally, and you control the pace. Perfect for side projects and individual contributors.
